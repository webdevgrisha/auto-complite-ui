# Setup Instructions

### 1. Clone the Repository

First, clone the repository to your local machine:

```bash
git clone https://github.com/rolling-scopes-school/webdevgrisha-EPAMPLLT.git
```

### 2. Install Dependencies

Navigate to the project folder and install all the dependencies using npm:

```bash
cd auto-complete-ui
npm install
```

### 3. Run the Project in Development Mode

To run the project in development mode with Webpack Dev Server, use the following command:

```bash
npm run start
```

This will start the server, and your project will be available at http://localhost:8080.

### 4. Build the Project

To create a production build of the project, run the following command:

```bash
npm run build
```

This will generate the bundled files in the dist/ folder.
